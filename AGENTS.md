# Правила агента — линия Apps (не‑1С)

1. Область = запрос пользователя. Не трогать `F:\AI_1C` и чужие Docker‑стеки 1С без явной просьбы.
2. Харнес общий: `F:\AI_Apps\harness`. Проект — `F:\AI_Apps\projects\<имя>` + `PROJECT.md`.
3. Секреты только в локальных env проекта, не в git harness.
4. Временное — в `harness/temp` или `projects/<имя>/temp`; по завершении удалять.
5. Не коммитить `.env`, ключи, токены. Не force-push.
6. 1С‑контуры (dolea/energy/mirax/rostviplast) — другая линия; не смешивать.
7. Эмуляторы BlueStacks (и другие тяжелые процессы: демоны сборки, временные серверы) запускать только на время работы,
   а когда не используются — закрывать: сразу после проверки, перед паузой или ожиданием (своего потока, сборки,
   ответа), в конце пачки и перед отчетом. Указание пользователя 03.11.2026: эмулятор держит ~3,5 ГБ памяти.
   Закрывать только свой экземпляр — по заголовку окна:
   `Get-Process HD-Player | ? MainWindowTitle -eq "<окно>" | Stop-Process -Force`, затем проверить, что окна нет.
   `CloseMainWindow()` не годится: BlueStacks только спрашивает «Желаете выйти?» и висит (04.11.2026 так три окна
   провисели два часа).
   Командная строка HD-Player не читается. Экземпляр 1С («BlueStacks App 1С», adb 5555) и чужие не трогать.
   Ярлыки, которые BlueStacks кладет на рабочий стол при установке, сразу убирать (в android —
   `projects\android\no_shortcuts.ps1`).
8. Разработку чаты делают не сами, а через субагентов (указание пользователя 05.11.2026: «все чаты не сами
   разрабатывают, а передают субагентам»). Чат — постановщик и приемщик: разбирается в задаче, пишет субагенту
   (Agent; большие и независимые задачи — Cursor/фоновые потоки по правилам проекта) полное задание — файлы, что
   сделать, как проверить, ограничения; затем проверяет результат сам (сборка, тесты, эмулятор) и отвечает
   пользователю. Сам чат правит только мелочь: опечатку, строку текста, номер версии, запись в README. Число
   одновременных субагентов — по остатку лимитов (правило проекта); пока субагент работает, чат свободен для новых
   задач пользователя.
