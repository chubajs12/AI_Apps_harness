# AI_Apps harness

Общее для **не‑1С** линии `F:\AI_Apps`. Проекты — в `F:\AI_Apps\projects\<имя>` с `PROJECT.md` → этот harness.

**Нет** 1С skills/rules/Vanessa/MCP‑1С — они только в `F:\AI_1C\harness`.

| Папка | Назначение |
|-------|------------|
| `docs/` | карта проектов, соглашения |
| `principles/` | принципы линии Apps |
| `workflows/` | типовые процессы |
| `adapters/` | интеграции (TG, API) без привязки к 1С |
| `skills/` | общие Apps‑skills (пока пусто / по мере появления) |
| `temp/` | временное; чистить после задачи |
